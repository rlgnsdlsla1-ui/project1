# VEX IQ · 3:1 속도 기어 빌드 가이드

드라이브 베이스에 **36T(모터) → 12T(바퀴)** 기어를 장착해 로봇 속도를 약 3배 올리는 수업용 빌드 인스트럭션입니다.

## 바로 열기

브라우저에서 `index.html`을 엽니다.

```bash
# 예: 로컬 미리보기
python3 -m http.server 8080 --directory vex-iq-3to1-speed
# → http://localhost:8080
```

## 수업 요약

| 항목 | 내용 |
|------|------|
| 목표 | Gear ratio로 속도 올리기 |
| 비율 | 36:12 = 3:1 (속도 ↑, 토크 ↓) |
| 전제 | 클로·드라이브 베이스 완성 후 |
| 단계 | 6 Step (부품 → 분리 → 36T → 12T → 정렬 → 테스트) |

## 폴더 구성

- `index.html` — 단계별 인터랙티브 가이드
- `images/` — 3D 스타일 조립 이미지
